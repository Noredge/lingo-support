Lingo 隐私政策

生效日期：2026-11-02 · 适用版本：1.3.0 起
发布者：Noredge · 联系方式：hongbin.lei98@gmail.com

你选择的文字，由你决定何时发送。

Lingo 是划词翻译与写作扩展。只有在你确认数据处理说明后，打开翻译窗口、点击写作操作或测试连接，扩展才会向 OpenAI 发起请求。扩展没有开发者运营的中转服务器、广告或分析服务。

1. 处理哪些数据

  • 选中文字与修改要求：所选网页内容、输入框或简单编辑器中的内容、目标语言、操作类型、自定义要求及模型返回的文字。你选取的文字可能包含个人通信或其他敏感信息，请仅选取你愿意交给 OpenAI 处理的内容。
  • 身份验证信息：你提供的 OpenAI API Key，仅用于向 OpenAI API 验证请求。可选的本机解锁密码只在本机加密或解锁时使用，不发送到 OpenAI 或开发者。
  • 设置：模型、默认语言、浮窗语言列表、站点暂停名单和数据处理确认状态保存在扩展本机存储中；网站授权由 Chrome 管理。
  • 当前页面信息：扩展在本机读取当前网站地址以判断授权及暂停状态、定位选区并执行你主动点击的替换。不会为分析或跟踪建立浏览历史，也不会把页面地址自动附加到模型请求中；如果你选中的文字本身包含网址，该网址会作为原文发送。

2. 数据发送给谁、用于什么

API 请求通过 HTTPS 直接发送到 https://api.openai.com/v1/responses，包含选中文字、任务所需指令、目标语言、模型及可选修改要求；API Key 放在身份验证请求头中。OpenAI 会收到处理请求所必需的网络信息，例如 IP 地址。测试连接发送固定示例句，而非页面内容。

开发者不接收或保存这些 API 请求。扩展不出售数据，不用于广告、信用评估或与翻译/写作无关的用途。不自动上传整页、整封邮件、附件、密码框或浏览历史；如果你主动选择整封邮件，所选全文仍属于请求内容。模型结果以纯文本显示，不作为远程代码执行。

3. 保存时间与密钥保护

  • 原文和结果仅保留于当前悬浮窗口内存；关闭窗口会清除该窗口会话，不建立文字历史。
  • 默认仅在 Chrome 的受限会话存储中保留 API Key；浏览器会话结束、扩展重载/停用后需重新填写或解锁。
  • 选择“加密保存到本机”时，持久存储只保存经 AES-256-GCM 加密的 Key、随机盐值、随机 IV 和算法参数。加密密钥由至少 12 个字符的解锁密码经 PBKDF2-HMAC-SHA-256（600,000 次迭代）派生；扩展不保存密码或持久化解密密钥。
  • 解锁后，明文 API Key 仅在当前浏览器会话内可用；网页内容脚本不能读取凭据存储。立即锁定会清除会话 Key，并停止扩展仍在进行的请求。已发送的请求无法从 OpenAI 撤回。
  • 从旧版本升级时，旧版明文持久 Key 先转入本次会话，再删除原持久字段；你需要主动设置密码才能加密保存。忘记解锁密码时无法恢复，只能删除加密副本并重新填写 Key。
  • 本机加密无法防护已控制浏览器或操作系统的恶意软件，也不保证抹除旧版备份或存储介质中的历史残留。密码管理器或系统备份由你自行管理。

Lingo 不使用 Chrome 云同步保存 Key 或设置。请求使用 store:false，但这不代表 OpenAI 服务端零保留；OpenAI 的日志、保留、处理地区及数据控制取决于其政策与您的账户配置，参见 OpenAI API 数据控制说明及隐私政策。

4. 用户选择与删除

你可不授权常驻网页访问，改用工具栏或右键临时调用；也可移除网站权限或暂停站点。取消数据处理确认并保存后，扩展不再发出新的模型请求。删除 Key 会删除会话和加密副本，但不会撤销 OpenAI 平台的 Key；撤销须在 OpenAI 平台完成。卸载扩展会移除该扩展的本机数据。已经复制或替换到网页中的内容由相应网站或应用管理，扩展无法替你删除其保存的数据。

5. 支持与政策网页

如果你通过电子邮件联系开发者，我们会收到你发送的邮箱、正文和附件，并仅用于答复与处理该问题；请勿发送 API Key、解锁密码或私人邮件内容。相关邮件在支持处理期间及必要的后续记录期间保留，你可联系同一邮箱请求删除我们持有的支持记录。

公开政策网页由 GitHub Pages 托管，不包含分析脚本或跟踪 Cookie。访问网页时 GitHub 可能处理常规托管日志，参见 GitHub 隐私声明。扩展内附带本政策的离线副本。

6. 更新与联系

政策发生变化时会更新本页日期；涉及实质性数据处理变化时，会在扩展中明确提示并在需要时重新取得同意。隐私或支持问题请联系 hongbin.lei98@gmail.com。

Lingo Privacy Policy

Effective November 2, 2026 · Version 1.3.0 onward
Publisher: Noredge · Contact: hongbin.lei98@gmail.com

Purpose and data processing

Lingo translates and edits text selected by the user. After you affirm the in-product data disclosure, opening the translation panel, requesting a writing operation or running the connection test sends a request directly to OpenAI over HTTPS. Selected text may include personal communications or other sensitive content. Send only text you intend OpenAI to process.

The request contains the selected text, necessary task instructions, model, target language and optional editing request. Your OpenAI API key is sent in the authentication header. OpenAI also receives network information needed to serve the request, such as your IP address. The connection test uses a fixed sample sentence. The developer operates no relay server and receives none of these API requests.

The extension uses the current page address locally to apply site permissions and pause settings; it does not append this address to API requests or record browsing history. URLs included in selected text are sent as part of that text. It does not automatically transmit whole pages, whole emails, attachments or password fields. If you intentionally select an entire email, that selection is transmitted. Results are displayed as text, never executed as remote code. No advertising, analytics, data sale or unrelated use is included.

Storage and security

Original text and results remain only in the current panel's memory and are discarded when it closes. Preferences, paused sites and consent status are stored locally, without Chrome cloud sync. Website permissions are managed by Chrome.

By default the API key is available only in restricted Chrome session storage. Optional persistent storage encrypts the key with AES-256-GCM using a key derived from your local password through PBKDF2-HMAC-SHA-256 with 600,000 iterations, a random salt and a random IV. Only ciphertext and public algorithm parameters are stored persistently. The extension does not store the password or a persistent decryption key. On restart/reload you must unlock again; while unlocked the plaintext key is available only within the current browser session. Content scripts cannot read credential storage.

Locking clears the session key and aborts ongoing extension requests; it cannot recall requests already received by OpenAI. Legacy plaintext keys are first moved to session storage and then removed from persistent storage. You must choose a password to persist them again. Forgotten passwords cannot be recovered. Local encryption does not protect against a compromised OS/browser, weak passwords, or historical backups of older data.

Requests use store:false; this is not a promise of zero retention by OpenAI. OpenAI's processing, logs and retention depend on its policies and account settings. See OpenAI data controls and privacy policy.

Your controls

You may use temporary invocation instead of persistent website access, revoke permissions, pause a site, revoke data consent in settings, lock the key, or delete both the encrypted and session copies. Deleting a key from Lingo does not revoke it at OpenAI. Uninstalling removes the extension's local data. Text you copy or insert into another website is controlled by that website.

Support, hosting and changes

Email support messages and attachments are used only to respond to your request and retained while resolving it and for necessary follow-up records. You may request deletion of support records. Never email API keys, unlock passwords or private message content. Public policy pages are hosted by GitHub Pages without analytics scripts; GitHub may process normal hosting logs under its privacy statement. An offline copy is bundled with the extension. Material changes will be disclosed and consent requested when needed. Contact hongbin.lei98@gmail.com.
